## 制作与验收

- 工具：`image_edit`（seedream_5.0_flash），以风格锚点 `trial1a.jpg` 为唯一主锚做图生图延展；白底输出后经 `mediakit-cli image remove-image-background`（scene=general）抠为透明 PNG；背景按要求保持不透明。
- 验收：画风与角色统一、单建筑无混入（无炮/旗/文字/人物等违禁元素——`base_age3` 因模型幻觉火炮与带字旗帜重试 2 次后通过；又因与古典城堡轮廓相近重绘 1 次，改为方形实心要塞体块后落盘）、真 RGBA 透明、命名与 art.md 资源键一致。
- 原件与中间文件：`assets/_work/buildings/raw/`（生成原图）与 `alpha/`（抠图后）。
- 5 个基地与 10 种防御塔已接入战场，防御面板显示对应塔图。共享战场背景也已接入，开启“简化背景”时回退 Canvas 简化场景。

## 运行资源与使用

原始 PNG 保持原样，运行 `python scripts/build-world-art.py`（需要 Pillow）生成 `assets/world-art/<资源键>.png` 和 `src/config/world-art.js` 索引。仅裁外围透明留白，基地最长边缩至 208 像素、塔缩至 96 像素，四周各加 4 像素透明边距，导出 RGBA PNG；不重新设计或修改原图。

基地按当前时代切换；朝向依据索引中的 `source_facing`，不能一律只翻转敌方：现代掩体原图入口在左，我方翻转、敌方保留；火药要塞和未来掩体入口在右，我方保留、敌方翻转。洞穴和城堡原图偏正面，保留原造型，我方保留、敌方镜像，内侧为出兵方向。所有炮塔原图朝右，我方保留、敌方翻转。塔按自身 `era` 与 `kind` 选择图片，基地进化不替换旧时代塔的造型。等级、塔位和阵营标记继续由 Canvas 绘制；建造、升级、出售的控件 ID 和规则不变。加载中或失败时回退原有建筑轮廓与塔图标。

`WorldArtService` 的建筑缓存按需加载、重复复用，最多 12 项 LRU，与角色立绘、特效及背景缓存独立。背景说明见 [战场素材说明](../battlefield/README.md)。运行包只包含 `assets/world-art/` 派生图，不包含 `assets/buildings/`、`assets/battlefield/` 或 `assets/_work/` 原图及制作资料。资源检查：`python scripts/check-world-art.py`。
