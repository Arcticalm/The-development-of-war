# 技能与命中特效素材说明

> 更新：2026-10-09；风格版本：`aow1-reference-v1`（与 30 兵立绘、基地/防御塔同一套 A 粗粝块面画风）。

按 `introduction/art.md` §6「技能特效」与「基础命中特效」生成并验收。所有特效为**横向 3 帧序列条**（时间从左到右），同一地面/命中锚点、透明背景、无角色/建筑/文字/UI、非整屏遮罩。

## 目录与命名

原图在 `assets/effects/`，文件名即资源键。均为透明 PNG（真 RGBA），画布 **3547×1182**。实际宽度不能整除 3，切片边界为 **0、1182、2365、3547**，三格宽度为 1182、1183、1182；不能将 `3547 / 3` 当作整数 1182。

## 制作与验收

- 工具：`image_edit`（seedream_5.0_flash），以已验收风格锚点（trial1a）为统一画风参考；白底输出后经 `mediakit-cli image remove-image-background`（scene=general）抠为透明 PNG。
- 制作验收记录：真 RGBA 透明（alpha 0–255）、画风与角色统一、横向三格序列。工作文件用系统临时目录处理，处理完即清理，项目内不留中间目录。接入时按实际像素修正上述切片余量。
- 5 种时代技能与 4 种基础命中特效已接入。原图保留不变，不重新绘制。

## 构建与运行

运行 `python scripts/build-world-art.py`（需要 Pillow），按上述整数边界保留全部像素列，把三格补齐到共同画布，再按三帧 alpha 并集统一裁边。每帧使用相同缩放和锚点，技能最长边 192 像素、命中最长边 96 像素，四周各加 4 像素透明边距，重新组合成等宽三帧条。导出至 `assets/world-art/<资源键>.png`；`src/config/world-art.js` 记录帧矩形、源切片边界、共同裁边、锚点与透明帧序号。

原图 `skill_age5` 的第 1、3 格完全透明，`hit_explosion` 第 3 格完全透明；透明格保留为消散阶段，不当作加载失败，也不复制其他格填充。其他帧中的地面、碎片等已绘制内容原样保留。

`BattleEffects` 只读取对局视图，在表现层重建技能与命中时序，不修改伤害、弹道、冷却、快照或协议。技能第 1 帧跟随 1 秒预警，第 2、3 帧各约 0.2 秒；古典箭雨按模型的三次脉冲重复后两帧。普通命中三帧共约 0.3 秒；已有范围爆炸约 0.4 秒。能量攻击用 `hit_energy`，爆破／溅射用 `hit_explosion`，其他攻击命中重甲／机械用 `hit_metal`，其余用 `hit_dust`。

帧龄统一使用战斗时钟，暂停与后台时停止；切换对局、时钟回退或效果到期清理。最多保留 32 个可见效果及 64 个事件标记。图片按需加载并复用，特效缓存最多 9 项，与建筑和角色缓存独立；加载失败回退简短图形。效果位于战场裁切区域、文字角色下方，不遮挡操作面板，随视角平移缩放。技能按钮使用当前时代的中间帧缩略图。

运行包只包含派生帧条，不包含 `assets/effects/` 原图。执行 `python scripts/check-world-art.py` 可复验三帧共同几何、透明边距、有效 alpha、透明帧与 3.5 MiB 包体预算。
