## 实际生成提示词

```text
Use case: stylized-concept. Asset: an original 2D side-scrolling strategy game character for a WeChat mini-program. Draw ONE complete unit, full body facing RIGHT in a clear side view, centered on a square canvas, all weapons, feet, mounts and machinery fully visible with generous margins. Consistent 3-head-tall cartoon proportions, strong readable silhouette, clean thick dark outlines, flat cel shading with two shade levels, earthy material colors with restrained muted teal faction-color accents. Polished hand-drawn 2D game illustration, not 3D, not photorealistic. Plain uncluttered backdrop; no scenery, no text, no logos, no watermarks, no UI, no frame, no blood. Preserve each unit’s documented equipment, era and role. Mounted units and artillery with an operator count as one composite unit. Do not include additional independent soldiers. Use the reference only to match drawing style, proportions, palette and line quality, never to copy the reference unit’s weapon or costume.

Unit: 投石猎手 (age1_range).
Character requirements from the project art guide:
#### 定位

原始时代后排远程单位。

#### 外观

体型比石棒战士瘦小，强调灵活感。

肩部背一个兽皮石袋，袋中露出几块圆形石头。

#### 武器

使用投石索或手持石块。

推荐使用 **投石索**，因为角色剪影与近战单位区别更加明显。

#### 攻击动作

取石 → 投石索旋转 → 身体后倾 → 向前投掷。

石块飞行采用明显抛物线。

#### 特效

石块命中地面产生：

- 小型尘土
- 碎石颗粒
```
